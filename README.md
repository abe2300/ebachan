# 定例経済ニュース報告アプリ

毎日の経済ニュース・税制改正情報を一覧表示する PWA アプリ。

## 🌐 公開URL
Netlify で公開されています（GitHub と自動連携）。

## 📁 主要ファイル
- `index.html` — メイン画面
- `manifest.json` — PWA マニフェスト
- `sw.js` — Service Worker
- `icon-192.png` / `icon-512.png` — アプリアイコン

## 🛠️ ローカル開発用
- `定例報告を起動.bat` — ローカルサーバー起動
- `定例報告サーバー停止.bat` — サーバー停止
- `server.py` — Python HTTP サーバー
- `_手順書再生成.py` — 運用手順書の再生成

## 📚 運用手順
詳細は `定例報告_運用手順書.docx` を参照。

## 🚀 自動デプロイ
このリポジトリへのプッシュは Netlify で自動デプロイされます。
